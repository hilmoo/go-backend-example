# Go Backend Example

This is an example project demonstrating how I build Go backends that are easy to develop, maintain, and fit into my workflow.

I will update this repository from time to time as I add more features or if I encounter scenarios where the project becomes difficult to maintain.

## Feature Highlights

* Echo Framework
* MCP Server
* Wide event logging
* No ORM
